### Code repository of [_Dynamics and control of highly pathogenic H5 avian influenza in a threatened pelican population_](https://www.biorxiv.org/content/10.64898/2026.03.16.712014v1)

- The main directory contains scripts for data cleaning, epidemiological modelling, carcass removal simulations, estimating seroprevalence, and plotting figures.
- Folder "phylo" contains a R script for genetic data analyses, maximum likelihood trees of the full genome segments, and a BEAST xml for generating the time-scaled HA phylogeny.
