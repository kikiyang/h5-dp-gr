### Code repository of paper: [Dynamics and control of highly pathogenic H5 avian influenza in a breeding population of Dalmatian pelicans (_Pelecanus crispus_)](https://doi.org/10.1016/j.epidem.2026.100955)

- The main directory contains scripts for data cleaning, epidemiological modelling, carcass removal simulations, estimating seroprevalence, and plotting figures.
- Folder "phylo" contains a R script for genetic data analyses, maximum likelihood trees of the full genome segments, and a BEAST xml for generating the time-scaled HA phylogeny.

Data availability:
1. [Outbreak time series and demographic data of Dalmatian pelicans at Lesser Prespa Lake, 2020--2022 (Original data)](https://doi.org/10.6084/m9.figshare.31462699)
2. [Virus genomic sequence and metadata hosted on GISAID, 2020-07-31 to 2022-08-01](https://doi.org/10.55876/gis8.260822fw)
