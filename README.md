Code and data for _Dynamics and control of highly pathogenic H5 avian influenza in a threatened pelican population_
- The main directory contains scripts for data cleaning, epidemiological modelling, and plotting.
- Folder "data" contains epidemiological and demographic data of the pelican population, and a metadata table of GISAID sequences used in the phylogenetic analysis.
- Folder "phylo" contains a R script for genetic data analyses, maximum likelihood trees of the full genome segments, and a BEAST xml for generating the time-scaled HA phylogeny.
